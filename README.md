# meerikuoppala.fi

Personal site of Meeri Kuoppala, served by GitHub Pages from the `main` branch
with the custom domain in `CNAME`.

Files:

- `index.html` – the whole site (Finnish first, English below; styles inline)
- `photo.jpg` – portrait, 800×800, also used as the social-share image
- `vieraskyna-hs-2026-09-14.png` – clipping of the HS Vieraskynä (14 Sep 2026)
- `suosituksia-suomalaiseen-politiikkaan.pdf` – policy recommendations (Finnish, 4 pp., co-authored), linked from the Mitä ehdotan section
- `robots.txt`, `sitemap.xml` – for search engines

Page sections: header with photo, intro, Mitä ehdotan · What I'm proposing
(summary quoted from the PDF; English is a translation), Haastattelut (interview cards with
YouTube thumbnails), Kirjoituksia ja lehtijuttuja (HS op-ed featured, then a
list), In English, Medialle ja yhteydenotot. Wording conventions: say "threat"
(uhka / sukupuuttouhka), never "risk"; say "superintelligent AI", not
"advanced AI"; avoid time-relative phrases like "this autumn".

Publishing: any commit pushed to `main` goes live at https://meerikuoppala.fi/
within a minute or two. After adding a new piece of writing, update the
`<lastmod>` date in `sitemap.xml`.
